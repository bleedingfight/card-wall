# 卡片墙 Card Wall

Chrome 扩展（Manifest V3）：磨砂玻璃风格的卡片化书签收藏墙。

## 功能

- **按书签大类分组展示**：分组区块纵向排列，组内卡片为**固定尺寸**（侧边栏开合只改变每行列数，卡片大小恒定），每页容量 N² 可配置（默认 4×4=16 张）；每组独立分页（圆点点击 / 触控板横向滚动即时切页；**触摸跟手翻页**——拖动实时平移、超半页松手翻页、未过半页硬币式衰减摆动复位、边界橡皮筋阻力），组头可点击折叠（状态持久化）
- **侧边栏**：折叠把手吸附在侧边栏右缘（收起后仍在屏幕左缘可拉开），开合时主区空间自动重排；悬浮搜索栏宽度实时对齐卡片网格的实际左右边界；分组区为**目录树**（点击目录行切换展开/收起——关闭则展开并右侧聚焦该目录，展开则收起且若正聚焦则返回全部；点击行不跳位，展开/收起只影响该行下方内容；书签节点带 favicon 点击直达），底部为单行标签条；右下角齿轮打开统一设置面板（壁纸方式：每日订阅/固定壁纸、透明度、布局 N×N、WebDAV 同步配置）
- **悬浮搜索条**：搜索框在卡片墙最上方，随右栏滚动始终吸附顶部；视图状态徽标（tag/分组/搜索/回收站过滤时的「📁 工具 · 10」样式提示）显示在侧边栏品牌下方，点击一键返回全部
- **tag 系统**：每张卡片可配置任意 tag（存插件私有 storage，按 URL 索引，不写进书签、与 Chrome 书签同步互不冲突）；侧边栏底部为单行标签条（`tag×数量` 样式），放不下时右侧按钮展开全部，点击 tag 过滤
- **删除联动书签**：删除卡片 = 书签移入回收站文件夹；只有清空回收站才真正删除书签
- **与浏览器书签实时双向同步**：卡片操作直接写 `chrome.bookmarks` 立即生效；书签管理器增删改、其他设备 Chrome 同步、网页右键收藏等任何层级变化，通过书签事件监听（150ms 去抖 + 拖拽保护 + 分页位置保留）立刻反映到卡片上
- **回收站**：真实书签文件夹（在「其他书签」下），随 Chrome 账号同步；可单卡恢复/彻底删除，或一键清空
- **WebDAV 同步**：tag 配置 + 背景设置可上传/拉取到任意 WebDAV 服务器（坚果云、Nextcloud 等），首次保存配置时按域名申请跨域权限
- **背景**：内置 5 款渐变 + 自定义图片 URL；支持**每日订阅源**——每日随机图（按日期做种子）、必应每日壁纸（自动抓取并缓存）、含 `{date}` 占位符的自定义 URL，每天自动换一张
- **外观可调**：卡片磨砂不透明度滑杆实时调节；布局 N×N 可配置
- **WebDAV 同步内容**：tag 配置 + 背景源/必应缓存 + 布局 + 透明度——换电脑拉取即恢复；侧栏开合、分组折叠等个人偏好不同步
- **拖拽操作**：拖动卡片到另一张卡片上调整顺序（左右半边区分插前/插后），跨分组拖动即移动分组；拖到侧边栏「♻ 回收站」即移入回收站；**拖到侧边栏目录树的文件夹上移入该目录**——悬停折叠目录约 0.6s 自动展开，可连续往深层拖（macOS Finder 式）；**树内拖到另一链接上 = 排序**（上下半区分插前/插后），真实书签顺序同步变化
- **一键导入书签**：把书签栏/其他书签中的收藏复制到卡片墙，文件夹层级自动变成分组，重复链接跳过，原书签不动
- **右键收藏（带目录选择）**：任意页面/链接右键 →「收藏到卡片墙」→ 弹出独立小窗展示卡片墙目录树，选目录、可改标题后收藏；主界面不再有手动添加入口
- **favicon**：通过 Chrome 内置 favicon 接口获取，失败回退首字母彩色块

## 数据流（设计要点）

| 数据 | 存储位置 | 说明 |
|---|---|---|
| 卡片/分组 | Chrome 书签 | 「书签栏/📌 卡片墙」文件夹，子文件夹=分组 |
| 回收站 | Chrome 书签 | 「其他书签/🗑 卡片墙回收站」，随账号同步 |
| tag | `chrome.storage.local` | 按 URL 索引（跨设备书签内部 id 会变，URL 稳定） |
| 背景/侧栏状态 | `chrome.storage.local` | |
| WebDAV 配置 | `chrome.storage.local`（AES-256-GCM 密文） | 口令经 PBKDF2 派生密钥加密；密钥只缓存在 `storage.session`（内存），口令永不落盘 |
| 同步文件 | WebDAV | `<配置路径>/card-wall-sync.json`，last-write-wins |

## 配置加密说明

- WebDAV 服务器地址、账号、密码整体用 **AES-256-GCM** 加密后存盘，磁盘上只有密文
- 加密口令由用户设置，通过 **PBKDF2-SHA256（150,000 次迭代）** 派生密钥，口令本身不存储
- 派生密钥缓存在 `chrome.storage.session`（纯内存），**浏览器重启后自动回到锁定状态**，点「⇅ 同步」输入口令解锁即可，解锁一次整个浏览器会话内有效
- 忘记口令：重新填写配置并设置新口令「加密保存」即可覆盖

## 安装（开发者模式）

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本目录
4. 新开一个标签页即是卡片墙

## 首次使用

1. 在书签栏会出现「📌 卡片墙」文件夹——可在 Chrome 书签管理器里往里建子文件夹（即分组）和书签（即卡片）
2. 鼠标悬停卡片右上角「✎」编辑 tag，「×」移入回收站
3. 侧边栏「⇅ 同步」配置 WebDAV 后，用 ↑/↓ 按钮上传/拉取
